# Quickstart Guide: Phase I Todo App

## Prerequisites
- Python 3.13 or higher
- Package manager: uv (or pip)

## Setup
1. Clone the repository
2. Navigate to the project directory
3. Install dependencies: `uv sync` (or `pip install -r requirements.txt`)

## Running the Application
1. Execute: `python main.py`
2. The console menu will appear with options to:
   - Add a new task
   - View all tasks
   - Update a task
   - Delete a task
   - Mark task as complete/incomplete
   - Exit the application

## Basic Usage
1. Select an option from the main menu
2. Follow the prompts to enter required information
3. The application will confirm your actions and display updated task list

## Example Workflow
1. Start the application
2. Choose "Add Task" and enter a title and optional description
3. Choose "View Tasks" to see your task list
4. Use other options to manage your tasks
5. Exit when finished (all data will be cleared)
